## Goal
Make every error response follow the API contract from `backend-core`: `{"error": "<message>", "code": "<machine.code>", "requestId": "<id>"}`, and return **409 Conflict** for optimistic-locking conflicts (`user.ErrConflict`) instead of 422. Covers pending items 2 and 3 of the `backend-go` skill.

## Scope
- `internal/platform/http/response.go` — `WriteError(w, r, status, code, msg)`, `WriteInternalError(w, r, err)`, `errorResponse` DTO
- `internal/user/http/errors.go` — `writeDomainError` status/code mapping
- `internal/user/http/handler.go` — call sites of `WriteError` (decode failures, invalid id) and swag `@Failure` annotations
- `test/e2e/user_test.go` — assertions on error bodies
- `docs/` regenerated by `make swag`
- `README.md` error-handling section (if present)

## Must not change
- Success responses (shape and status).
- Which domain error maps to 400/401/403/404 today; only `ErrConflict` moves (422 → 409).
- `X-Request-ID` middleware behavior.

## Tasks
- [ ] Add `code` and `requestId` to `errorResponse`; `WriteError` reads the id with `platformhttp.RequestIDFromContext(r.Context())`
- [ ] Add `WriteInternalError(w, r, err)` that logs `error` + `request_id` via `slog` and responds 500 with code `internal_error` and a generic message (never leaks `err.Error()`)
- [ ] Define the code vocabulary for the user context: `request.invalid_body`, `user.invalid_id`, `user.invalid` (name/email/password/role), `user.email_already_exists`, `user.not_found`, `user.version_conflict`, `user.invalid_credentials`, `user.inactive`
- [ ] Map `user.ErrConflict` → 409 `user.version_conflict`; keep `ErrEmailAlreadyExists` → 409 `user.email_already_exists`
- [ ] Update swag `@Failure` lines on `Register`, `Find`, `Update` (409 now also covers stale version; 422 no longer mentions version) and run `make swag`
- [ ] e2e: assert `code` and non-empty `requestId` on at least one 400, 404, 409 (email) and 409 (stale version) response; assert `requestId` equals the `X-Request-ID` response header
- [ ] Unit test for `WriteError`/`WriteInternalError` in `platform/http` using `httptest` (body shape, no error leak on 500)

## Done when
- `go build`, `go vet`, `golangci-lint run` clean
- `make test`, `make test-e2e` pass with the new assertions
- `grep -rn 'StatusUnprocessableEntity' internal/user/http/errors.go` shows no `ErrConflict` in the 422 branch
- Swagger regenerated and committed
